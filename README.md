# ibsheet-react-sample

[`@ibsheet/react`](https://github.com/ibsheet/ibsheet-react-component) sample for react

## Clone Project

```bash
git clone https://github.com/ibsheet/ibsheet-react-sample.git ibsheet-react-sample
cd ibsheet-react-sample
```

## Copy IB Sheet Library

copy to: `public/assets/ibsheet`

## Start

### Using npm:

```
npm install
npm dev
```

### Using yarn:

```
yarn
yarn dev
```
